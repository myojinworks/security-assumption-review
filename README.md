# Security Assumption Review Prompt

A public reference prompt for **ethical hackers and defensive security teams**.

This prompt helps an authorized reviewer identify which security conclusions are supported by evidence, which rely on assumptions, and what remains unknown. It is a supplement to—not a substitute for—professional security testing, threat modeling, incident response, or vendor advisories.

## Contents

- [prompt.md](./prompt.md) — the complete English-language Security Assumption Review Prompt, also published as part of the related Medium article.

## How to use

1. Copy the complete text from `prompt.md` into an AI assistant approved for your assessment.
2. Replace the placeholders with information from a system you are **authorized** to assess.
3. Keep sensitive information, credentials, keys, and customer data out of unapproved AI services.
4. Verify every consequential claim against system evidence, official vendor advisories, and independent professional judgment.

## Scope and limitations

- Defensive, permission-based, non-destructive review only.
- Findings are *not verified vulnerabilities* merely because an AI suggested them.
- An absence of findings is not proof that a system is secure.
- Do not treat patch installation as proof that no prior compromise occurred.
- Do not use this prompt to authorize access or testing beyond the agreed scope.
- No validated performance advantage over established security-review methods is claimed.
